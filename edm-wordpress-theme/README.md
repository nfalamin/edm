# EDM WordPress Theme & SaaS Control Plane Installation Guide

## 📦 Theme Package
* **Folder Location:** `d:\Update EDM\EDM\edm-wordpress-theme\`
* **Ready-to-Upload ZIP:** `d:\Update EDM\EDM\edm-wordpress-theme.zip`

---

## 🚀 How to Install in WordPress (১ ক্লিকে ইনস্টল করার নিয়ম):

### ধাপ ১: থিম আপলোড করুন
1. আপনার ওয়ার্ডপ্রেস অ্যাডমিনে লগইন করুন (`yourdomain.com/wp-admin`)।
2. বামপাশের মেন্যু থেকে যান: **Appearance ➡️ Themes**।
3. উপরে থাকা **Add New Theme** বাটনে ক্লিক করুন।
4. **Upload Theme** বাটনে ক্লিক করুন এবং **`Choose File`** থেকে সিলেক্ট করুন:
   `d:\Update EDM\EDM\edm-wordpress-theme.zip`
5. **Install Now** এ ক্লিক করুন এবং ইনস্টল শেষে **Activate** বাটনে ক্লিক করুন।

---

### ধাপ ২: পেজ সেটআপ করুন

#### ১. হোমপেজ (Landing Page):
* থিম অ্যাক্টিভেট করলেই আপনার ওয়েবসাইটের মূল হোমপেজে স্বয়ংক্রিয়ভাবে **EDM Public Landing Page** চালু হয়ে যাবে।

#### ২. অ্যাডমিন ড্যাশবোর্ড (Admin Control Plane):
* ওয়ার্ডপ্রেস ড্যাশবোর্ড থেকে যান: **Pages ➡️ Add New Page**।
* পেজের নাম দিন: **`Dashboard`** (অথবা `Control Plane`)।
* ডানপাশের **Page Attributes / Template** অপশন থেকে ড্রপডাউনে সিলেক্ট করুন:
  👉 **`EDM Admin Dashboard`**
* **Publish** বাটনে ক্লিক করুন।
* এখন আপনার ড্যাশবোর্ড লাইভ দেখতে ভিজিট করুন: `https://yourdomain.com/dashboard/`

---

## 🌟 থিমের মধ্যে যা যা রয়েছে:
1. **পাবলিক ল্যান্ডিং পেজ:** ৩২-স্ট্রিম ডাউনলোড সিমুলেটর, ফিচারস গ্রিড, এক্সটেনশন ইন্টিগ্রেশন, স্ক্রিনশট গ্যালারি, চেঞ্জলগ এবং এফএকিউ।
2. **অ্যাডমিন ড্যাশবোর্ড:** ৭টি টপ KPI কার্ড উইথ লাইভ স্পার্কলাইনস, ইন্টারেক্টিভ ভেক্টর ওয়ার্ল্ড ম্যাপ, ডাবল-লাইন ইউজার গ্রোথ চার্ট, মাইক্রোসার্ভিস হেলথ টেবিল, কম্বো অ্যানালিটিক্স চার্ট এবং ট্রায়াল কনভার্সন ডোনাট চার্ট।
3. **ফুল রেসপন্সিভ:** মোবাইল, ট্যাবলেট এবং ডেস্কটপে পারফেক্ট অপ্টিমাইজড।
