# ⚠️ Antigravity-কে প্রতিটি Step-এর আগে যে নিয়ম দিতে হবে

প্রতিটি Step-এর prompt-এর শুরুতেই আমি এই ধরনের instruction রাখব:

> **“এই কাজ শুরু করার আগে আমার repository-এর actual code, file structure, dependency এবং existing implementation গভীরভাবে inspect করো। কোনো code অনুমান করে লিখবে না। যে সমস্যা বলছো তার exact file path, class, method এবং প্রয়োজন হলে line reference দাও। কোনো কিছু ইতিমধ্যে ভালোভাবে implement করা থাকলে সেটা আবার rewrite করবে না। আগে diagnosis, তারপর plan, তারপর implementation। একটি change করার আগে তার impact অন্য service-এ কী হবে যাচাই করো। কাজ শেষে build/test চালিয়ে ফলাফল দেখাও। কোনো test/build সম্ভব না হলে স্পষ্টভাবে বলো। তুমি 100% correct ধরে নেবে না—প্রতিটি assumption actual code দিয়ে verify করবে।”**

এটা খুব গুরুত্বপূর্ণ।
