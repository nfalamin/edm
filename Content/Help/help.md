# Help & Support Guide

### Quick Start
1. Run EDMSetup.exe and complete installation.
2. Install the browser extension from the Extensions Hub.
3. Click any download link in your browser; EDM will automatically intercept and accelerate the transfer.

### Troubleshooting
- **Download Stalled**: Click 'Resume' or verify network connectivity.
- **Extension Not Intercepting**: Ensure the NativeHost component is registered under HKCU\Software\Google\Chrome\NativeMessagingHosts.
