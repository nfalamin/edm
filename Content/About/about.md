# About Exclusive Download Manager (EDM)

Exclusive Download Manager (EDM) is a next-generation Windows desktop accelerator engineered for ultra-fast, uninterrupted, multi-threaded file and media retrieval.

## Key Architecture
- **32 Parallel TCP Sockets**: Dynamic byte-range splitting bypassing ISP single-stream bandwidth throttling.
- **Intelligent Media Sniffing**: Instant detection of high-bitrate video and audio streams across 500+ web platforms.
- **Native Host Integration**: Zero-lag communication between browser extensions and the C# .NET 8 core engine.
- **Private Telemetry Control Plane**: Real-time fleet health, release management, and encrypted diagnostics.
